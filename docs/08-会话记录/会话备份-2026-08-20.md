## 💡 关键决策记录

### 决策 1: 两种分析模式并存
- **选择**: 保留原有 `AgentLoopService`，新增 `DeepAgentLoopService`
- **原因**: 向后兼容，用户可选择不同分析深度
- **实现**: 在 `AnalysisMode` 枚举中添加 `DEEP`，在 `AiService` 中根据模式选择服务

### 决策 2: 深度分析输出格式
- **选择**: 使用结构化的 `DeepAnalysisResult` 而非简单 Markdown
- **原因**: 支持前端精细化展示，每个洞察可独立交互
- **结构**: executiveSummary + context + keyInsights + criticalAnalysis + actionableTakeaways

### 决策 3: 前端重构方案
- **选择**: 分屏工作台 + 洞察卡片 + 证据时间轴
- **原因**: 提升交互体验，让视频和分析紧密关联
- **参考**: YouTube 章节、Notion AI、Descript
