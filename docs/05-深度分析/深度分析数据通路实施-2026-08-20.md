# 深度分析数据通路实施方案

> **最后更新**：2026-08-20

## 📋 问题描述

之前 DEEP 模式的分析结果被扁平化为 Markdown 存储，丢失了推理过程、批判分析等结构化数据。前端无法访问这些结构化数据来展示洞察卡片等组件。

## ✅ 解决方案

采用 **方案 A：扩展 MediaFile 实体**，在保留 Markdown 格式的同时，额外存储结构化的 JSON 数据。

---

## 🔧 实施内容

### 1. 数据库层

**新增字段**：`deep_analysis_json` (JSON 类型)

**迁移脚本**：`V4__add_deep_analysis_json.sql`
```sql
ALTER TABLE media_files
ADD COLUMN deep_analysis_json JSON NULL 
COMMENT '深度分析结果的结构化 JSON 数据';
```

### 2. 实体层

**修改文件**：`MediaFile.java`

新增字段：
```java
private String deepAnalysisJson;  // 存储 DeepAnalysisResult 的 JSON 格式
```

### 3. 服务层

**修改文件**：`AiService.java`

- 注入 `ObjectMapper` 依赖
- 修改 `persistDeepResult()` 方法：
  - 保存 Markdown 格式（向后兼容）
  - 同时保存结构化的 JSON 数据

```java
// 保存 Markdown 格式（向后兼容）
mediaFile.setAiSummary(deepResult.toMarkdown());

// 保存结构化的 JSON 数据（新增）
try {
    mediaFile.setDeepAnalysisJson(objectMapper.writeValueAsString(deepResult));
} catch (Exception e) {
    log.warn("Failed to serialize DeepAnalysisResult to JSON", e);
}
```

### 4. 控制器层

**修改文件**：`AnalysisController.java`

新增 API 端点：`GET /analysis/deep-result`

```java
@GetMapping("/deep-result")
public Result<DeepAnalysisResult> deepAnalysisResult(
        @RequestParam Long id,
        @RequestAttribute(AuthService.REQUEST_USER_ID) Long userId) {
    MediaFile mediaFile = mediaService.requireOwnedMedia(id, userId);
    if (mediaFile.getDeepAnalysisJson() == null) {
        return Result.ok(null);
    }
    try {
        DeepAnalysisResult result = objectMapper.readValue(
                mediaFile.getDeepAnalysisJson(), DeepAnalysisResult.class);
        return Result.ok(result);
    } catch (Exception e) {
        log.warn("Failed to deserialize deep analysis result for mediaId={}", id, e);
        return Result.ok(null);
    }
}
```

## 🚀 使用方法

### 1. 启动应用

```bash
cd server
./mvnw spring-boot:run
```

Flyway 会自动执行数据库迁移，添加 `deep_analysis_json` 字段。

### 2. 提交深度分析任务

```bash
# 登录获取 token
TOKEN=$(curl -s -X POST http://localhost:9090/user/login \
  -H "Content-Type: application/json" \
  -d '{"username":"lwj123","password":"12345678"}' | jq -r '.data.token')

# 提交 DEEP 模式分析
curl -X POST http://localhost:9090/analysis/ai \
  -H "Authorization: Bearer $TOKEN" \
  -d '{
    "mediaId": 1,
    "goal": "深度分析视频核心观点",
    "mode": "DEEP"
  }'
```

### 3. 获取结构化结果

```bash
# 获取结构化的深度分析结果
curl -X GET "http://localhost:9090/analysis/deep-result?id=1" \
  -H "Authorization: Bearer $TOKEN"
```

返回示例：
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "executiveSummary": "...",
    "keyInsights": [...],
    "criticalAnalysis": {...},
    ...
  }
}
```

## 🎨 前端集成

### API 调用

```javascript
// 获取结构化深度分析结果
async function getDeepAnalysisResult(mediaId) {
  const response = await fetch(`/analysis/deep-result?id=${mediaId}`, {
    headers: {
      'Authorization': `Bearer ${token}`
    }
  });
  const result = await response.json();
  
  if (result.code === 0 && result.data) {
    // 有结构化数据，使用新组件展示
    return result.data;
  } else {
    // 没有结构化数据，降级到 Markdown 展示
    return null;
  }
}
```

### 组件展示

```vue
<template>
  <div v-if="deepResult">
    <!-- 使用结构化数据展示洞察卡片 -->
    <InsightCard 
      v-for="insight in deepResult.keyInsights" 
      :key="insight.insight"
      :insight="insight"
    />
    
    <!-- 批判性分析 -->
    <CriticalAnalysis 
      :analysis="deepResult.criticalAnalysis" 
    />
    
    <!-- 可操作收获 -->
    <ActionableTakeaways 
      :takeaways="deepResult.actionableTakeaways" 
    />
  </div>
  <div v-else>
    <!-- 降级到 Markdown 展示 -->
    <MarkdownRenderer :content="markdownContent" />
  </div>
</template>
```

## ✅ 向后兼容性

- **普通模式（GENERAL/LEARNING/REVIEW/CREATION）**：继续使用 `aiSummary` 字段存储 Markdown
- **深度模式（DEEP）**：同时存储 Markdown 和 JSON
- **前端降级**：如果 `deepAnalysisJson` 为 null，前端可以降级到 Markdown 展示
- **现有 API**：所有现有 API 保持不变，新增 `/analysis/deep-result` 端点
